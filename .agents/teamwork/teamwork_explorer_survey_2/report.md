## 3. Производные ассеты, которые необходимо сформировать для `20_Сайт_Беслана`

Для обеспечения **100% автономной работы сайта офлайн** (без интернета, без внешних CDN, без тормозов) необходимо при развертывании проекта сгенерировать 2 дополнительных легковесных файла из `beslan.mp4`:

### А. Автономный аудио-трек `beslan.mp3`
- **Зачем:** Для интеграции легкого музыкального аудиоплеера (винил, кассета, неоновый эквалайзер, аудиоволна Wavesurfer), не требующего рендеринга видеоэлемента.
- **Команда генерации (FFmpeg):**
  ```powershell
  ffmpeg -y -i "c:\Users\evgen\Desktop\Antigravity\NEWprodject\17_Бесроллинг\public\assets\beslan.mp4" -vn -ab 192k -ar 44100 "c:\Users\evgen\Desktop\Antigravity\NEWprodject\20_Сайт_Беслана\public\assets\beslan.mp3"
  ```
- **Характеристики результата:** Размер всего **~273 КБ**, стерео 44.1 кГц, 192 кбит/с, чистейший звук вокального хука Беслана.

### Б. Постер-кадр `beslan_poster.jpg`
- **Зачем:** Чтобы тег `<video poster="/assets/beslan_poster.jpg">` отображал четкий кадр из видео до запуска, без черного экрана или мерцания при предзагрузке.
- **Команда генерации (FFmpeg):**
  ```powershell
  ffmpeg -y -ss 00:00:02 -i "c:\Users\evgen\Desktop\Antigravity\NEWprodject\17_Бесроллинг\public\assets\beslan.mp4" -vframes 1 -q:v 2 "c:\Users\evgen\Desktop\Antigravity\NEWprodject\20_Сайт_Беслана\public\assets\beslan_poster.jpg"
  ```
- **Характеристики:** Размер **~27 КБ**, 406×720 px.

## 6. Рекомендации по интеграции плеера, вирусности и букинга

### 1. Архитектура плеера и воспроизведение «0 мс без буферизации»
- **Локальный приоритет:** При загрузке страницы использовать HTML5 медиа-элемент с `preload="auto"`. Браузер мгновенно кэширует 1 МБ видео и 273 КБ аудио.
- **Преодоление блокировки автоплея (Autoplay Policy):**
  - Современные браузеры блокируют автовоспроизведение со звуком без прямого жеста пользователя (User Gesture).
  - В проекте 17 успешно применена элегантная двухходовая механика: аккуратный интерактивный оверлей (согласие на cookie по 152-ФЗ / кнопка «Включить секретный трек» / клик по виниловой пластинке), клик по которому **синхронно** стартует воспроизведение со 100% громкостью без единой миллисекунды задержки.
- **Iframe Fallback:** На случай редких сбоев локального видео предусмотреть скрытый `<iframe>` с `https://www.instagram.com/reel/DcQU8MDAMpV/embed/`.

### 2. Спецпроект и пасхалка «Бесроллинг» (Rickroll по-кавказски)
- В интерфейсе сайта Беслана обязательно должна присутствовать интерактивная фича:
  - **Кнопка в навигации / карточке:** *«Забесроллить друга 😈»* или секретная кнопка в футере.
  - При нажатии открывается стильная модальная панель (генератор ссылок-ловушек) либо запускается полноэкранный Бесролл с эффектом *«You just got Beslaned!»*.
  - Это создает мощный вирусный виток: фанаты и посетители сайта сами начинают делиться сайтом Беслана в Telegram и WhatsApp.

### 3. Секция коммерческого букинга (Booking & Live Shows)
Для превращения сайта в реальный инструмент продаж выступлений Беслана Тлихураева необходимо включить в интерфейс:
- **Форматы выступлений:**
  1. *Сольный концерт с live-бэндом* (фанк, поп-программа «Путешествие в детство»).
  2. *Акустический сет / Камерный вечер* (рояль, гитара, вокальные баллады).
  3. *Выступление на закрытых мероприятиях и премиальных событиях* (свадьбы, юбилеи, корпоративные шоу).
  4. *Театральные и мюзикловые коллаборации*.
- **Технический и бытовой райдер:** Ссылка на скачивание или краткая спецификация (микрофонный парк, мониторинг, клавишные/гитарные линии).
- **Интерактивная форма заказа концерта:**
